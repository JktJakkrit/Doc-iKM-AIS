How this table works

Each Header / sub header has a top-right icon toggling Locked / Auto (closed lock) and Unlocked (open lock). All rows start in Locked / Auto: repeated values appear as a grey ~; group headings remain editable and changes flow to consecutive matching Auto cells, skipping Unlocked cells. New rows inherit headings from the preceding row in the same tab (or the first row when inserted at the top), so Copy / Excel omit repeated headings. Unlock a cell to enter a different heading for that row only. Switching back keeps your edits and restores automatic grouping.

The export keeps all 9 sample columns. With several source files, pick a tab to view or edit one file; export combines them into one workbook with one sheet each. Only the Link column carries the hyperlink: it shows “URL” in Excel, and “เปิดลิงก์ ↗” in the preview. Detail is plain text and editable on every row. Use the pencil in Link to edit its full URL, then Save; PDF rows offer “Use original URL” to restore their source destination. Cancel discards the draft. Insert rows by clicking the circled + at a row boundary; the green line is a non-clickable position indicator (the button is also accessible with Tab then Enter or Space, and always visible on touch screens). Reorder rows by dragging ⠿, and delete rows (✕) before exporting. New or edited URLs need a full http(s) URL.
